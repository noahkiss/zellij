# Removed patches

Features this fork once carried and removed. Each row says where the code still lives, so it
can be brought back. `git revert <removal commit>` restores one while the base is unchanged;
after a rebase, port it from the last release that had it.

| Feature | What it did | Last release with it | Removed in | Where to find it | Why removed |
|---|---|---|---|---|---|
| `pane_privacy` | A `pane_privacy { patterns_file pattern match_fields on_unknown_cwd tab_rule }` config block (or `ZELLIJ_PANE_PRIVACY_FILE`) hid matching panes and tabs from `list-panes`, `list-tabs`, `list-tree`, `list-agents`, `action watch` and the MCP, with a `withheld` count behind `--report-withheld`. | `v0.45.1-nkmk.40` | (this commit) | `zellij-server/src/pane_privacy.rs`, `zellij-utils/src/pane_privacy.rs`, `pane_privacy_refusal` and `strip_withheld_cwds` in `zellij-server/src/route.rs`; FORK.md "`pane_privacy`: panes the session keeps to itself" and "`pane_privacy` and `resurrect_command_hints` warn on a key they do not know" | No machine configured a policy, and its guard over every action in `route.rs` was a large divergence to carry at each rebase. |
| Session manager extras | The session manager's `Ctrl+e` archive picker (restore a snapshot, `Ctrl+r` to restore under another name), its `Ctrl+l` attached-client list with `d` to detach one client and each client's size, its `<CURRENT>` row and its "why the list is empty" notices; with them the plugin API `list_snapshots`, `restore_snapshot`, `detach_clients`, `Event::ListSnapshots`, `Event::SnapshotRestoreFailed` and the `ClientInfo` terminal size fields. | `v0.45.1-nkmk.40` | (this commit) | `default-plugins/session-manager/src/snapshot_picker.rs`, `client_list.rs`, `main.rs`, `single_screen.rs`, `ui/components.rs`; `snapshot_infos` in `zellij-utils/src/session_snapshot.rs`; `restore_snapshot`, `list_snapshots`, `detach_clients` in `zellij-server/src/plugins/zellij_exports.rs`; FORK.md "The session manager says why its list is empty", "The session manager lists the attached clients, and detaches one of them", "The session manager picks a session out of the archive", "The session manager's client list actually lists clients", and "A plugin can read the archive" / "A plugin can restore one" under "The session snapshot archive" | No use found; the CLI (`zellij snapshot`, `list-clients`, `action detach`) covers each job, and upstream 0.46 rewrites the session manager. |

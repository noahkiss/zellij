# v0.46.0-nkmk.45

- **Upstream base:** unchanged — the `v0.46.0` release tag (`aedee21cb`)
- **Range:** `v0.46.0-nkmk.44..v0.46.0-nkmk.45`
- **Released:** 2026-11-24

This release stops a tab from ignoring clicks and scrolling after a tab switch, and lets the config keep a stale variable out of every new pane.

## Fixed

- **A lost mouse release no longer freezes a tab.** Since nkmk.41 (the 0.46 base), a click on the tab bar held a selection in the tab you left, because the bar switches tabs on the press and the release lands in the next tab. Back in that tab, scrolling and tab-bar clicks did nothing until one click into a pane. Leaving a tab now forgets its held mouse gestures, and a press during a held gesture ends it first, so a release lost any other way (released outside the window, an app switch mid-drag) costs nothing either.

## Added

- **`pane_env_drop`** names environment variables every new pane goes without: exact names, or a prefix ending in `*`. A pane inherits the server's environment, frozen when the session was created, so a variable exported then and stale since reached every new pane. A config reload applies a changed list to the panes spawned after it, with no restart. A name the `env {}` block sets is kept, and zellij's own `ZELLIJ*` variables are never dropped. Capability: `pane-env-drop`.

## Upgrading

- Both changes are in the server: a session picks them up when it restarts onto this build. `session status` reports the restart as needed.
- `pane_env_drop` is a top-level key, so an older build ignores it. The shared config can carry it before every machine runs this build.
- A running pane keeps its own environment. Open a new pane, or restart the session, to leave a dropped variable behind.

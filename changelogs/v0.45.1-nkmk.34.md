# v0.45.1-nkmk.34

- **Upstream base:** unchanged — the `v0.45.1` release tag (`efd8fd5a8`), plus the one commit
  taken ahead of the next base in nkmk.22
- **Range:** `v0.45.1-nkmk.33..main`
- **Released:** 2026-10-12

This release is about one agent driving others. `action drop-file` stores a file on the session's
machine and pastes the reference the pane's program reads, from one `ssh` command. The MCP gains a
supervision loop: `zellij_create run_in=agent` starts an agent from a brief, `zellij_wait_for
until=agent_idle` waits for its turn to end, `zellij_read_pane last_reply` reads what it said,
`zellij_write_input` submits, approves, interrupts and hands it a file, and `zellij_overview
scope=my_agents` shows the agents the caller started. opencode reports its state, a PNG a program
sent reaches the terminal as that PNG, and a restored agent pane holds only its bare resume in
every `resurrect_commands` mode. Nothing crosses a contract.

## Added

### `action drop-file`: hand a pane a file, from any machine

```
$ ssh host zellij action drop-file --pane-id sunny-otter --name shot.png < shot.png
path: /home/u/.cache/zellij/drops/drop-6f1c2a9e-….png
bytes: 48213
pane_id: terminal_3
handle: sunny-otter
agent: claude
form: at
reference: @/home/u/.cache/zellij/drops/drop-6f1c2a9e-….png
```

- The bytes come from a path or stdin, and land in `drops/` in the zellij cache directory:
  `0700`, each drop `0600`, written whole or not at all, 25 MiB at most, pruned after seven days.
- The reference follows the pane's program: `@/abs/path` for claude, opencode and pi, the bare
  path for codex, a shell-quoted path at a shell.
- It is a bracketed paste and one space. Enter is never pressed.
- The pane is looked up first: a miss stores nothing and reads no stdin.

### The MCP supervision loop

- **`zellij_create run_in=agent`** with `command` (claude, codex, opencode or pi, and its flags)
  and `brief` (a file). The pane's shell reads the brief as the first prompt; the call returns the
  handle. `kind` takes `floating`, and the `floating` flag stays. `zellij_create` has ten
  parameters, and the cap is ten.
- **`zellij_wait_for until=agent_idle`** and **`until=agent_waiting`**, or `action wait --for
  agent-idle|agent-waiting`. They read the `OSC 7501` state, and only a state reported after the
  last input counts. An agent that reports no state is judged by silence. Capability:
  `wait-agent-state`.
- **`action last-reply`** and **`zellij_read_pane last_reply`** print the agent's last reply from
  its own transcript (claude, codex, pi), not from the screen. Capability: `last-reply`.
- **`zellij_write_input`** gains `submit` (paste the text, then Enter), `agent_action`
  (`interrupt`, `approve`, `deny`, each only when the agent's state fits) and `file` (runs
  `drop-file`; never presses Enter).
- **`zellij_overview scope=my_agents`** lists the agents in the caller's own `-zj` tab. Agent rows
  gain `state_age_s` and `output_age_s`, and `list-agents --json` rows gain `last_output_at`.

### opencode reports its state

The TUI plugin from `zellij setup --agent-hooks` writes `OSC 7501` for opencode 1.x and 2.x:
`working`, `blocked` on a permission or a question, `done`, and `error`. `list-agents` shows it
with `state_app` `opencode`.

## Changed

### A PNG goes to the client as the PNG the program sent

An image a program sent as PNG (`f=100`), shown at its own size, goes to each terminal as that PNG
when it is smaller than the zlib payload. A 410x520 screenshot crop fell from 277,554 bytes to
243,527. A scaled placement still goes as zlib-compressed RGBA.

## Fixed

### A restored agent pane holds only its bare resume, in every mode

Under the default `resurrect_commands "all"`, a known agent was recorded with its whole argv, so a
restore offered to send its launch prompt again. Now claude, codex, opencode and pi are recorded as
their bare resume, or their picker, in every mode. Every other command keeps its argv. The
`list-panes` and `list-agents` tables fold a newline in a cell to a space.

## Operator notes

- **opencode state needs the new TUI plugin.** Re-run `zellij setup --agent-hooks` and re-install
  the opencode TUI file.
- **A snapshot written before nkmk.34** still holds the old command under `"all"`. A restore from
  it offers that command once; the next serialization records the bare form.
- **Nothing crosses a contract.** A restart picks the changes up.

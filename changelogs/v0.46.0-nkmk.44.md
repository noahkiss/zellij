# v0.46.0-nkmk.44

- **Upstream base:** unchanged — the `v0.46.0` release tag (`aedee21cb`)
- **Range:** `v0.46.0-nkmk.43..v0.46.0-nkmk.44`
- **Released:** 2026-11-21

This release makes an upgrade reach a session nobody is attached to, and makes every session subcommand honor the global `--session`.
The server is unchanged from nkmk.43: a session that runs nkmk.43 needs no restart.

## Added

- **An upgrade reaches a session nobody is attached to.** The watchdog's `session up` now notices a newly installed build, refreshes the pin from it, and restarts the session onto it when no client is attached and no agent is working. A session with a client attached keeps its build until someone restarts it. A release candidate, a stock build or another fork is never pinned. `session_service { upgrade_restarts "never" }` turns the restart off; the default is `"clientless"`.

## Fixed

- **Session subcommands honor the global `--session`.** `zellij --session X session restart` restarted the session the shell was in. Every session subcommand now takes its name from the argument, else `--session`, else the current session, else the config's `session_name`. An argument and a different `--session` refuse with exit 2 and change nothing.

## Changed

- `session up`, `down`, `enable`, `disable`, `status` and `doctor` without a name now act on the current session before the config's `session_name`, as `restart` already did.

## Upgrading

- Run `session enable` once to refresh the pin. From this release on, the watchdog refreshes it by itself.
- The restart-needed mark lists nkmk.43 as the same server, so `session status` reports no restart needed for a session on nkmk.43.

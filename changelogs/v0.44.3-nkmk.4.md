# v0.44.3-nkmk.4

- **Upstream base:** `v0.44.3`
- **Range:** `5a1f7974b..ab7b15164` (19 commits: 11 code, 4 CI, 3 doc, the version bump)
- **Released:** 2026-08-03

*Back-written 2026-08-10 from the git history and FORK.md.*

The release that makes a session scriptable. A caller can now ask what a session contains, wait for
one to be gone, save one, and put it back — and the CLI stops returning success for work it did not
do. Prebuilt fork binaries also start shipping on tag.

## Sessions

- The session snapshot archive: `zellij snapshot`, `zellij snapshot import`, `attach --restore`,
  and a named error when the contract does not match.
  See [The session snapshot archive](../FORK.md#the-session-snapshot-archive).
- `delete-session` and `kill-session` wait for the server process to exit, with `--wait-timeout`
  and `--no-wait`. Server teardown was fixed to match: it now takes the pane shells with it instead
  of lingering for minutes.
  See [`delete-session` and `kill-session` wait for the server to actually be gone](../FORK.md#delete-session-and-kill-session-wait-for-the-server-to-actually-be-gone).
- The socket directory is shown, and `ls` warns about sessions outside it.
  See [The socket directory is visible](../FORK.md#the-socket-directory-is-visible-and-ls-warns-about-sessions-outside-it).

## Panes and tabs

- `--stacked` fails loudly when it has no client and no target, instead of quietly creating
  nothing; the refusal exits non-zero.
  See [`--stacked` fails instead of quietly creating nothing](../FORK.md#--stacked-fails-instead-of-quietly-creating-nothing).
- `list-panes --json` reports `pane_pid`.
  See [`pane_pid` in `list-panes --json`](../FORK.md#pane_pid-in-list-panes---json).
- `PaneInfo` reports program title and stack membership.
  See [Pane identity and stack membership in `PaneInfo`](../FORK.md#pane-identity-and-stack-membership-in-paneinfo).
- Absolute tab reorder with `move-tab --to-index`, defaulting to the active tab.
  See [Absolute tab reorder](../FORK.md#absolute-tab-reorder-move-tab---to-index).

## Release plumbing

- CI publishes prebuilt fork binaries on tag, and the install and release procedures are
  documented.
- The Intel Mac target is dropped; `macos-13` is retired, so Intel builds moved to `macos-15-intel`
  first.

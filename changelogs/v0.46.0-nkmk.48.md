# v0.46.0-nkmk.48

- **Upstream base:** unchanged — the `v0.46.0` release tag (`aedee21cb`)
- **Range:** `v0.46.0-nkmk.47..v0.46.0-nkmk.48`
- **Released:** 2026-11-27

The MCP `zellij_create` now makes a pane and runs nothing in it; `zellij_write_input` types the
command. A pane made together with its command read as spent once the command failed, so agents
made a new pane for each retry. The server is unchanged from nkmk.47: a session that runs nkmk.47
needs no restart.

## Changed

### `zellij_create` makes a ready shell pane; the command goes in second

```
zellij_create {"cwd": "~/src/app"}
  # ready: true, ready_by: prompt, pane_cwd: /home/<user>/src/app, cwd_honoured: true
zellij_write_input {"pane": "sunny-otter", "text": "cargo test", "submit": true}
```

| parameter | default | effect |
|---|---|---|
| `wait_ready` | `true` | the answer is a shell ready for input; `false` answers at once |
| `exec` | none | a one-shot run as `$SHELL -c <exec>`, the pane's own process; `zellij_wait_for until=exit` reads its `exit_status` |

- `command` and `run_in` are refused by name, with the two steps to use instead: make the pane,
  then type with `zellij_write_input`, and keep the pane.
- A shell pane takes no name. Its title is what its shell sets: the directory at the prompt, the
  command while one runs.
- The pane is still read back for `pane_cwd` and `cwd_honoured`. The read-back now retries every
  100 ms for up to 1 s, so a fresh tab's cwd measurement no longer races it.
- `exec` ignores `wait_ready`, and its pane is named after the command and ends with it.

## Removed

- `zellij_create`'s `command` and `run_in`. `docs/removed-patches.md` says where the code lives.

## Upgrading

- **Behaviour change for MCP callers:** a `zellij_create` call with `command` or `run_in` fails
  with the two-step hint. A client that enforces the schema's `additionalProperties: false`
  refuses the call itself. Pass `exec` for a one-shot whose exit status you want.
- The change lives in `zellij mcp`, a client process. The restart-needed mark lists nkmk.47 as the
  same server, so `session status` reports no restart needed for a session on nkmk.47. An MCP
  server already running keeps the old tool until its client restarts it.
- Nothing crosses a contract.

# v0.45.1-nkmk.35

- **Upstream base:** unchanged — the `v0.45.1` release tag (`efd8fd5a8`), plus the commit taken in nkmk.22
- **Range:** `v0.45.1-nkmk.34..rc/nkmk.35`
- **Released:** 2026-10-14

This candidate adds remote MCP sessions, configured pane stacks, and live agent names.
A timed-out screen match now explains what counts as new output.
Agent-change waits wake supervisors, and the harness map exports shared facts and screen rules.

## Added

### Remote hosts over ssh

MCP tools accept `session="host/session"` for hosts listed in the top-level `remote_hosts` block.
`zellij_overview scope=fleet` lists agents across those hosts, including unreachable hosts and older builds.
Files and agent briefs travel over ssh stdin.
Remote creation supports `agent_tab` and `tab`.
`stacked` requires the caller's local pane.

```kdl
remote_hosts {
    from "~/.config/fleet/machines.tsv" column="hostname" where="zellij_peer=yes"
    host "boxa"
    host "boxb" bin="/opt/homebrew/bin/zellij"
}
```

The machine table uses tabs and a header row.
`column` selects the host column.
`where` filters rows without case sensitivity.
Table host names become lowercase, and inline entries override matching table entries.
The MCP reads the table again on each call that needs it.
Invalid entries produce warnings.
Ssh never prompts for passwords or host keys.

### CLI pane defaults and MCP stacks

Set `new_pane_default "stacked"` to stack unplaced `run`, `action new-pane`, and `edit` commands.
The default remains `"split"`.
Explicit placement flags retain their behavior.
Without a valid caller pane, the CLI explains the fallback and creates a split.
The setting stays outside the client/server contract.

MCP `zellij_create kind` accepts `stacked`, `agent_tab`, and `tab`.
`agent_tab` remains the default and reuses the caller's agent tab.
`stacked` stacks onto the caller's pane.
The tool rejects the former `pane` and `floating` kinds and the `floating` parameter.
`zellij_show` retains its floating image viewer.

### Live agent names and caller context

- `zellij list-agents` aliases `action list-agents` and adds a `NAME` column.
- JSON rows carry `name` and `self`. The caller's table row shows `(you)`.
- Claude names follow verified live session records. Other harness names remain null.
- `zellij action whoami` reports the caller and other agents, with optional JSON output.
- The Claude SessionStart hook supplies caller context and current agent names.
- `pane_frame_agent_name true` prefixes pane titles with live names and reloads without restarting.
- Successful MCP input to a named agent adds a messaging hint.
- MCP exposes an `agents` prompt and a `zellij://agents` JSON resource.

## Fixed

### A timed-out `wait --for match` explains a missed match

The timeout message names the pattern and explains the baseline and duplicate-line rules.
The regex matches one screen line at a time.
`^` and `$` anchor to that line.
When the wait starts, text already visible never counts.
A line identical to one already visible does not count as new output.
Matching behavior remains unchanged.

### Removed MCP placement options fail before a brief upload

The MCP rejects removed kinds and the `floating` parameter before reading or uploading an agent brief.

### Silent agents refresh their names on the detection tick

A Claude process waiting silently can acquire its session identity and messaging name without writing pane output.
The detection tick now discovers foreground agents every second.
Record contents stay cached until the file's modification time or foreground process changes.
Missing and malformed records remain cached until they change.
A valid record overrides the process environment's session id.
If the record disappears, the environment fallback returns and the cached name clears.

### Stacked terminals keep their expanded size

Collapsed stacked panes retain the expanded pane's terminal rows and columns.
The terminal grid and PTY use the same dimensions, including frame offsets.
Stack resizing updates every terminal immediately.
Changing focus within a stack does not shrink the collapsed terminals.
New stacked panes receive their terminal size at creation, before a client renders them.
`list-panes` still reports each pane's visible geometry.

## Harness map

`zellij setup --harness-map` prints inventories for Claude, Codex, OpenCode, and Pi.
Add `--json` for the schema-versioned inventory and detector manifests.
The command needs no session and reads no installed harness files.
Each fact includes its source, revision, and verification marker.

The fork vendors four verbatim Herdr manifests, their license, notices, and screen fixtures.
Separate fork supplements describe question footers and first-run gates.
The screen evaluator preserves regions, priorities, nested gates, exclusions, and engine requirements.
It returns unknown for unmatched screens and preserves transcript-viewer skip behavior.
Synthetic screens remain marked unverified against installed releases.
The map supplies a public evaluator. Agent-change retains its existing fallback detector in this release.

## agent-change

`action wait --for agent-change` waits for state, name, identity, appearance, or exit changes.
Repeat `--pane` to select agents. Without `--pane`, the wait watches every agent except the caller.
The result includes the pane handle, tab, harness, name, old/new states, and a last reply line.
Exit 0 reports a change. Exit 2 reports a timeout or session failure.

`list-agents --watch --changes-only` streams change records as NDJSON without an initial agent list.
MCP exposes `zellij_wait_for until=agent_change`, with an optional `pane` target.
The client samples internally, so supervisors can use one blocking wait.
Without native state, the fallback screen detector recognizes trust gates, question menus, and Codex rate-limit gates.
A Codex rate-limit screen counts as blocked.
Capability: `wait-agent-change`.

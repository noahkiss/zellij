# v0.46.0-nkmk.43

- **Upstream base:** unchanged — the `v0.46.0` release tag (`aedee21cb`)
- **Range:** `v0.46.0-nkmk.42..v0.46.0-nkmk.43`
- **Released:** RELEASE-DATE

This release makes agent messages reach a busy or OpenCode agent, and makes the macOS session watchdog cheap.
Long messages arrive as a short stub, and a queued message can be read in full or cancelled.
A session the lifecycle commands create never shows upstream's desktop-setup screen.
A running session needs a restart to use this release.

## Added

- **Messages to an OpenCode agent go through OpenCode's own API.** zellij finds the TUI's private server through the pane's process tree and posts the message as a synthetic message: the TUI shows one `↳ <sender> finished` line, the model gets the whole message, and nothing is typed over a draft. A pane where this fails gets the typed message as before.
- **Long messages arrive as a stub.** A message whose paste would pass 600 characters is pasted as its first line and a pointer; `zellij action message-show <id>` prints the whole text. A short message is unchanged, so Claude Code still collapses it.
- **`zellij action message-cancel <id>`** cancels a message the session still holds. The MCP `zellij_send` takes `cancel` with the message's session.
- **A sender hears when its message expires undelivered**, when the sender is an agent pane in the same session.
- **`session doctor` reports the Microphone grant on macOS**, as information: granted, not asked yet, or denied with the Settings link. It never needs a person and never changes the exit code.

## Changed

- **A message reaches a Claude agent whose turn ended while background work runs.** Claude Code keeps reporting `working` while subagents or background shells run; the guard now reads Claude's own session record, and `idle`, `waiting` and `shell` count as free. A draft and typing still hold the message.
- **A session that `session up`, `restart` or the watchdog creates never shows the desktop-setup screen**, and a restore drops a setup pane a snapshot carried. A plain `zellij` is unchanged.

## Fixed

- **The macOS watchdog's `session up` starts about 3 processes, not hundreds.** It ran `ps`, `launchctl` and `plutil` by bare name, and each spawn failed once per PATH directory before the right one; it also converted Apple's own launch agents with `plutil`. The tools now run by absolute path, and `/System/Library/LaunchAgents` is not scanned.

## Compatibility

- **Restart needed: yes.** The server changed.
- **New actions** `message-show` and `message-cancel` take fork tags 908 and 909. An older server answers neither.
- **Exit codes:** `message-show` exits 1 for an unknown id; `message-cancel` exits 1 for a message that is no longer held.
- **JSON keys** are only added: a message record may carry `via` and the status `cancelled`.

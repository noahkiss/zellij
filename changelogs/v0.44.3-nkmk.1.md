*Back-written 2026-08-10 from the git history and FORK.md.*

The first fork release. It carries two groups of patches: plugin development ergonomics, and
session lifecycle that tells the truth.

- Hot-reload plugins from disk, and pre-grant their permissions from the config.
  See [Plugin hot-reload](../FORK.md#plugin-hot-reload-plugin_watch-default-on) and
  [Declarative plugin permissions](../FORK.md#declarative-plugin-permissions).
- Plugin reload recovers instead of wedging the plugin pane.
  See [Plugin reload no longer wedges](../FORK.md#plugin-reload-no-longer-wedges).
- `dump-screen` works on plugin panes.
  See [`dump-screen` works on plugin panes](../FORK.md#dump-screen-works-on-plugin-panes).
- A deleted session no longer resurrects from its final snapshot.
  See [`delete-session` no longer leaves a ghost](../FORK.md#delete-session-no-longer-leaves-a-ghost).
- `zellij ls -s` marks exited sessions.
  See [`zellij ls -s` marks exited sessions](../FORK.md#zellij-ls--s-marks-exited-sessions).
- `attach --no-resurrect` attaches without reviving a dead session.
  See [`attach --no-resurrect`](../FORK.md#attach---no-resurrect).

`FORK.md` itself lands in this release as the patch ledger.
